Goal

Papers, patents and lab notes mention chemicals by trade names, common names, IUPAC names, abbreviations and CAS numbers. This project builds one large local database of chemical names and synonyms, each tied to a PubChem CID, an InChIKey and a SMILES string, plus cross-references to ChEBI, ChEMBL, DrugBank, UNII and CompTox. A dictionary matcher runs over that lexicon at text-scanning speed, and a name-to-structure parser and an NER model handle names the dictionary has never seen.

Name → CID → SMILES/InChIKey for ~119M compounds. Free, flat TSV files.

Systematic namesOPSIN

Parses IUPAC-style names that no dictionary contains straight into SMILES/InChI.

Finding spansDictionary + NER model

Aho-Corasick over a cleaned lexicon for speed, plus an NER model for unseen names.

Cross-referencesUniChem + curated sources

InChIKey-keyed joins add ChEBI, ChEMBL, DrugBank, HMDB, CompTox and more to each CID.

Pipeline

  1. Build the master table keyed on InChIKey. Load PubChem CID-InChI-Key, CID-SMILES and CID-Title, then join ChEBI, ChEMBL, DrugBank vocabulary, UNII, CompTox and HMDB by InChIKey (or use UniChem for all IDs at once). DuckDB reads the gzipped TSVs directly and writes Parquet.
  2. Build the lexicon. Union of PubChem filtered synonyms, ChEBI names, ChEMBL synonyms, DrugBank, UNII, CompTox and MeSH entry terms, each pointing to a CID. Normalize Unicode (NFKC), dashes, primes and Greek letters (α↔alpha), collapse whitespace, and case-fold everything except short all-caps abbreviations.
  3. Clean it. Drop common English words that need context (lead, gold, tin, iron), 1–2 character entries, pure numbers and database-ID strings. When a name maps to several CIDs, keep a ranked list, preferring the CID whose title matches, then the one with more sources.
  4. Match fast. Compile the lexicon into an Aho-Corasick automaton (pyahocorasick, or the Rust aho-corasick crate) with leftmost-longest matching and word-boundary checks. A compressed trie or FST (marisa-trie, Rust fst) keeps tens of millions of names within a few GB of memory.
  5. Add regex matchers for CAS RNs (\d{2,7}-\d{2}-\d with checksum), InChIKeys and molecular formulas.
  6. Catch unseen names. Run an NER model for spans the dictionary missed, send each to OPSIN, compute the InChIKey with RDKit and look it up in the master table.
  7. Store results as (span, name, CID, InChIKey, SMILES, xrefs, method), where method is dictionary, OPSIN or model, so precision can be audited per route.
# sketch: build lexicon + lookup with DuckDB and pyahocorasick
import duckdb, ahocorasick
con = duckdb.connect("chem.duckdb")
con.sql("""CREATE TABLE syn AS SELECT column0::BIGINT cid, lower(column1) name
           FROM read_csv('CID-Synonym-filtered.gz', delim='\t', header=false, quote='')""")
con.sql("""CREATE TABLE smi AS SELECT column0::BIGINT cid, column1 smiles
           FROM read_csv('CID-SMILES.gz', delim='\t', header=false, quote='')""")

A = ahocorasick.Automaton()
for cid, name in con.sql("SELECT min(cid), name FROM syn WHERE length(name) > 3 GROUP BY name").fetchall():
    A.add_word(name, (name, cid))
A.make_automaton()          # pickle this; rebuild only when sources update

def find(text):
    t = text.lower()
    for end, (name, cid) in A.iter_long(t):   # leftmost-longest
        start = end - len(name) + 1
        if (start == 0 or not t[start-1].isalnum()) and (end+1 == len(t) or not t[end+1].isalnum()):
            yield start, end + 1, name, cid

Evaluation corpora

  • CHEMDNER: 10,000 PubMed abstracts, ~84k chemical mentions; the standard benchmark.
  • BC5CDR: 1,500 abstracts with chemicals normalized to MeSH.
  • NLM-Chem: 150 full-text PMC articles with MeSH-normalized chemicals.
  • CHEMDNER-patents and ChEMU 2020: patent text, including reaction roles.

Scoring will cover span F1 and CID accuracy. Most corpora are mirrored in the BigBio collection on Hugging Face.

Get started: download the data

scripts/download_datasets.sh fetches the open sources into scripts/data/<source>/. It is resumable (partial files continue with curl -C -), checks free disk space first, and works with macOS bash 3.2 and Linux bash.

git clone https://github.com/Autonomous-Scientific-Agents/Chemical-Name-Extractor.git
cd Chemical-Name-Extractor/scripts
./download_datasets.sh                       # all sources, ~48 GB compressed
./download_datasets.sh pubchem chebi unii    # or pick sources
./download_datasets.sh --dest /Volumes/Big/chem --verify
